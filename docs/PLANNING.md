# Projectplanning — Boekenwinkel

## 1. Projectdoel

Het doel is om een applicatie voor een fictieve boekenwinkel te bouwen.
Gebruikers kunnen boeken bekijken, reserveren en reviews schrijven.
De applicatie houdt de beschikbare voorraad bij.

## 2. Technologieën

- Backend: Java 21 en Spring Boot
- Database: MySQL
- Databasetoegang: Spring Data JPA
- Frontend: HTML, CSS en JavaScript
- Tests: JUnit en Spring Boot Test
- Versiebeheer: Git en GitHub

## 3. Projectfases

### Fase 1 — Voorbereiding
- Git en GitHub instellen
- Projectstructuur aanmaken
- Planning en architectuur documenteren

### Fase 2 — Backend en database
- Spring Boot-project aanmaken
- Databaseverbinding configureren
- Datamodel ontwerpen

### Fase 3 — Boekencatalogus
- Boeken toevoegen, bekijken, wijzigen en verwijderen
- ISBN uniek maken
- Beschikbare voorraad beheren

### Fase 4 — Gebruikers
- Registratie implementeren
- Login en beveiliging implementeren
- Gebruikersprofiel voorzien

### Fase 5 — Reserveringen
- Boeken reserveren
- Beschikbare voorraad controleren
- Voorraad correct aanpassen
- Bevestiging met afhaalinformatie voorzien

### Fase 6 — Reviews
- Gekochte boeken aan gebruikers koppelen
- Scores en reviewteksten opslaan
- Reviews op boekdetailpagina's tonen

### Fase 7 — Frontend
- Boekencatalogus bouwen
- Boekdetailpagina maken
- Registratie en login bouwen
- Reserveringen en profiel tonen
- Frontend met de REST API verbinden

### Fase 8 — Testen
- Boekencatalogus testen
- Voorraadwijzigingen testen
- Reserveringen testen
- Gebruikersfunctionaliteit testen
- Foutscenario's controleren

### Fase 9 — Afronding
- README en API-documentatie afwerken
- Testresultaten documenteren
- Bronnen en AI-gebruik vermelden
- GitHub-repository controleren
- Definitieve inzending voorbereiden

## 4. Werkwijze

Het project wordt in kleine, controleerbare stappen ontwikkeld.
Na elk afgerond onderdeel worden de wijzigingen getest en
met een duidelijke commitboodschap in Git opgeslagen.

## 5. Kwaliteitscriteria

- Backend en frontend zijn aparte projecten.
- De applicatie gebruikt een database voor permanente opslag.
- Kritieke functionaliteiten hebben geautomatiseerde tests.
- API-endpoints en belangrijke codeonderdelen zijn gedocumenteerd.
- Externe bronnen en AI-hulp worden vermeld in de README.
